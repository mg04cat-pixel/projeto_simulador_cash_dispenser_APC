# simulador_cash_dispenser_APC
Repositório dedicado a códigos, testes e projeto em grupo do Simulador de Cash Dispenser

# Anotações Gerais

## O que o programa faz
1. Armazena a quantidade de cada nota disponível (10 20 50 e 100)
2. Permite o reabastecimento de notas
3. Exibir o estoque de notas
4. Processar saque com base em notas disponíveis

- Se houver notas, ele aceita o saque, se não, ele nega
